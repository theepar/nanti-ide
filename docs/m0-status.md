## Manual IME checklist (needs a person with a CJK IME; not automated)

1. Run `cargo run -p ui` on a folder with a text file; open it; click into the editor.
2. Switch to an IME (e.g. Microsoft Pinyin). Type `nihao`: pre-edit text must appear underlined at the caret and the candidate window must sit next to the caret.
3. Pick a candidate: text is committed, underline disappears, the tab shows the dirty dot.
4. Ctrl+Z once: the whole composition disappears in one step.
5. Repeat inside the palette (status bar **Commands**): the query must accept composition and the editor text must not change.
6. Select text, then start composing: the selection is replaced by the pre-edit text.
Record the IME name/version and the result for each step here.
